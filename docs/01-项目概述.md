# InterviewCoach 项目开发文档

## 1. 项目概述

### 1.1 项目简介

InterviewCoach（面试教练）是一款面向程序员面试准备的微信小程序，核心功能是帮助用户通过解析招聘要求（JD）来生成针对性的面试题目进行模拟面试练习。

### 1.2 核心功能

- **JD智能解析**：自动提取招聘要求中的技能关键词、技术栈、经验要求等
- **面试题生成**：根据解析结果生成针对性的技术面试题和软技能问题
- **模拟面试**：支持多种题型，包括概念题、手写代码题、系统设计题等
- **历史记录**：保存面试记录，支持回顾和分析
- **面试报告**：生成详细的面试练习报告

### 1.3 技术架构

- **前端框架**：微信小程序原生框架
- **开发语言**：JavaScript/TypeScript
- **数据存储**：本地存储（wx.setStorageSync）
- **核心算法**：基于关键词权重的JD解析算法
