# JD解析模块开发文档

## 1. 模块概述

JD解析模块（`services/jd-parser.js`）负责解析招聘要求文本，提取关键信息，包括技术栈、经验要求、学历要求等，为面试题生成提供数据支持。

## 2. 功能说明

### 2.1 核心功能

| 功能 | 说明 |
|------|------|
| 关键词提取 | 从JD文本中提取技术关键词 |
| 技能分类 | 将关键词按编程语言、框架、数据库等分类 |
| 经验提取 | 解析JD中的工作年限要求 |
| 学历提取 | 解析JD中的学历要求 |
| 职位提取 | 提取职位名称 |

### 2.2 关键词权重配置

关键词根据重要程度配置了不同的权重值：

```javascript
// 编程语言权重
languages: {
  JavaScript: 1.0, 
  TypeScript: 1.2,  // 加分项
  Python: 1.0,
  Java: 1.0,
  Go: 1.1,
  Rust: 1.1,
  // ...
}

// 框架权重
frameworks: {
  React: 1.2,
  Vue: 1.2,
  'Spring Boot': 1.2,
  // ...
}
```

## 3. 接口定义

### 3.1 parseJD(jdText)

**功能**：解析JD文本，提取关键信息

**参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| jdText | string | 是 | JD文本内容 |

**返回值**：

```javascript
{
  success: true,                    // 是否成功
  keywords: [                       // 提取的关键词
    {
      name: 'React',                // 关键词名称
      count: 3,                     // 出现次数
      weight: 1.2                   // 权重值
    }
  ],
  skills: {                         // 分类后的技能
    languages: [...],
    frameworks: [...],
    databases: [...]
  },
  summary: {                        // 摘要信息
    position: '前端开发工程师',      // 职位名称
    experience: { required: 3 },   // 经验要求
    education: { required: '本科' },// 学历要求
    totalKeywords: 15,             // 关键词总数
    topSkills: ['React', 'Vue']   // 核心技能
  }
}
```

### 3.2 generateSkillTags(keywords)

**功能**：根据关键词生成技能标签

**参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| keywords | Array | 是 | 关键词数组 |

**返回值**：技能标签数组，如 `['前端', '全栈', '数据库']`

## 5. 使用示例

```javascript
// 引入模块
const { parseJD, generateSkillTags } = require('./services/jd-parser.js')

// 解析JD
const jdText = `
  招聘前端开发工程师
  要求：
  1. 3年以上前端开发经验
  2. 精通React和TypeScript
  3. 熟悉Node.js和数据库
`

const result = parseJD(jdText)

if (result.success) {
  console.log('职位:', result.summary.position)
  console.log('核心技能:', result.summary.topSkills)
  console.log('关键词列表:', result.keywords)
}

// 生成技能标签
const tags = generateSkillTags(result.keywords)
console.log('技能标签:', tags)
```

## 6. 注意事项

1. **关键词匹配**：使用正则表达式 `\bkeyword\b` 进行精确匹配，避免部分匹配
2. **文本预处理**：自动转换为小写进行匹配，但保留原始大小写返回
3. **性能考虑**：关键词匹配按类别分组，避免重复遍历
4. **扩展性**：关键词权重配置可独立修改，无需修改核心逻辑
