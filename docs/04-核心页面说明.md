# 核心页面说明文档

## 1. 首页 (pages/index)

### 1.1 功能说明

- 展示小程序主要功能入口
- 显示用户面试统计数据
- 轮播展示面试小贴士
- 提供快捷功能入口

### 1.2 页面结构

```
index
├── 顶部欢迎区域
│   ├── 标题：面试教练
│   └── 副标题：智能面试准备助手
├── 功能入口卡片
│   ├── 输入JD
│   ├── 面试历史
│   └── 使用帮助
├── 快捷功能区
│   ├── 快速开始
│   ├── 题库浏览
│   ├── 面试统计
│   └── 分享小程序
└── 面试小贴士（轮播）
```

### 1.3 主要方法

| 方法名 | 说明 |
|--------|------|
| loadStatistics() | 加载面试统计数据 |
| navigateToJDInput() | 跳转到JD输入页 |
| navigateToHistory() | 跳转到历史页 |
| quickStart() | 快速开始面试 |
| showHelp() | 显示帮助信息 |

---

## 2. JD输入页 (pages/jd-input)

### 2.1 功能说明

- 输入和编辑招聘要求文本
- 提供快捷模板选择
- 配置面试题目数量和难度
- 验证输入并跳转到面试

### 2.2 页面结构

```
jd-input
├── 页面标题
├── JD输入区域（textarea）
├── 快捷模板选择
│   ├── 前端开发
│   ├── 后端开发
│   ├── 全栈开发
│   └── 移动端
├── 面试设置
│   ├── 题目数量（5-50）
│   └── 难度级别（全部/初级/中级/高级）
└── 开始面试按钮
```

### 2.3 主要方法

| 方法名 | 说明 |
|--------|------|
| onJDInput(e) | JD文本输入处理 |
| selectTemplate(e) | 选择快捷模板 |
| adjustQuestionCount(e) | 调整题目数量 |
| selectDifficulty(e) | 选择难度级别 |
| startInterview() | 开始面试 |

### 2.4 页面间数据传递

| 传递方式 | 键名 | 说明 |
|----------|------|------|
| Storage | currentJD | 当前JD文本 |
| Storage | interviewSettings | 面试设置 |

---

## 3. 面试页 (pages/interview)

### 3.1 功能说明

- 展示当前面试题目
- 收集用户回答
- 提供提示和参考答案
- 记录面试进度
- 支持收藏题目

### 3.2 页面结构

```
interview
├── 顶部进度区
│   ├── 进度信息（当前/总数）
│   ├── 进度条
│   └── 计时器
├── 题目卡片
│   ├── 题目标签（类型/难度/关联）
│   ├── 题目内容
│   └── 题目提示
├── 回答区域
│   ├── 文字回答（textarea）
│   └── 代码编辑（代码题专用）
├── 操作按钮
│   ├── 上一题
│   ├── 提交并下一题
│   └── 跳过
└── 底部功能
    ├── 提示
    ├── 参考答案
    └── 收藏
```

### 3.3 主要方法

| 方法名 | 说明 |
|--------|------|
| onLoad() | 页面加载，初始化面试数据 |
| onAnswerInput(e) | 回答输入处理 |
| submitAnswer() | 提交当前回答 |
| prevQuestion() | 上一题 |
| nextQuestion() | 下一题 |
| showHint() | 显示提示 |
| showAnswer() | 显示参考答案 |
| markQuestion() | 收藏题目 |
| saveToHistory() | 保存到历史记录 |

### 3.4 弹窗组件

| 弹窗 | 说明 |
|------|------|
| showHintModal | 题目提示弹窗 |
| showAnswerModal | 参考答案弹窗 |
| showCompleteModal | 面试完成弹窗 |

---

## 4. 历史页 (pages/history)

### 4.1 功能说明

- 展示面试历史记录列表
- 支持按时间筛选
- 显示面试统计数据
- 支持查看详情和删除

### 4.2 页面结构

```
history
├── 统计概览
│   ├── 面试次数
│   ├── 完成题目
│   └── 累计时长
├── 筛选标签
│   ├── 全部
│   ├── 今天
│   ├── 本周
│   └── 本月
└── 历史列表
    └── 历史项
        ├── 职位信息
        ├── 日期
        ├── 完成情况
        └── 展开详情
            ├── 技能标签
            ├── 摘要信息
            └── 操作按钮
```

### 4.3 主要方法

| 方法名 | 说明 |
|--------|------|
| loadHistory() | 加载历史记录 |
| calculateStats() | 计算统计数据 |
| changeFilter(e) | 切换筛选条件 |
| applyFilter() | 应用筛选 |
| toggleExpand(e) | 展开/收起详情 |
| viewDetail(e) | 查看详情 |
| rePractice(e) | 再练一次 |
| deleteItem(e) | 删除记录 |

---

## 5. 结果页 (pages/result)

### 5.1 功能说明

- 展示面试报告详情
- 显示JD解析结果
- 展示题目完成情况
- 支持分享和重新开始

### 5.2 页面结构

```
result
├── 报告头部
│   ├── 图标
│   ├── 标题
│   ├── 日期
│   └── 职位
├── 概览统计
│   ├── 完成率（环形图）
│   ├── 完成题目数
│   └── 总用时
├── JD解析结果
│   ├── 编程语言
│   ├── 框架技术
│   ├── 数据库
│   └── 工具和DevOps
├── 题目详情
│   └── 题目列表
│       ├── 题目编号
│       ├── 题目类型
│       ├── 题目内容
│       ├── 用户回答
│       └── 代码答案
└── 操作按钮
    ├── 分享报告
    └── 开始新面试
```

### 5.3 主要方法

| 方法名 | 说明 |
|--------|------|
| loadReport(id) | 加载指定报告 |
| loadLatestReport() | 加载最新报告 |
| generateReport() | 生成报告数据 |
| toggleQuestion(e) | 展开/收起题目 |
| shareReport() | 分享报告 |
| startNewInterview() | 开始新面试 |

---

## 6. 页面生命周期

### 6.1 生命周期函数

| 页面 | onLoad | onShow | onUnload |
|------|--------|--------|----------|
| index | ✓ | 刷新统计 | - |
| jd-input | ✓ | - | - |
| interview | ✓ 初始化数据 | - | ✓ 停止计时 |
| history | ✓ | 刷新数据 | - |
| result | ✓ 加载报告 | - | - |

### 6.2 数据持久化

| 数据 | 存储键名 | 说明 |
|------|----------|------|
| 用户信息 | userInfo | 登录用户信息 |
| 当前JD | currentJD | 当前面试的JD |
| 面试设置 | interviewSettings | 面试参数设置 |
| 面试历史 | interviewHistory | 历史记录列表 |
| 收藏题目 | markedQuestions | 收藏的题目ID列表 |

---

## 7. 路由配置

在 `app.json` 中的路由定义：

```javascript
{
  "pages": [
    "pages/index/index",      // 首页
    "pages/jd-input/jd-input", // JD输入
    "pages/interview/interview", // 面试
    "pages/history/history",   // 历史
    "pages/result/result"     // 报告
  ],
  "tabBar": {
    "list": [
      { "pagePath": "pages/index/index" },
      { "pagePath": "pages/jd-input/jd-input" },
      { "pagePath": "pages/history/history" }
    ]
  }
}
```
