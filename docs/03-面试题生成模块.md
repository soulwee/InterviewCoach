# 面试题生成模块开发文档

## 1. 模块概述

面试题生成模块（`services/question-generator.js`）是面试教练小程序的核心服务，负责根据JD解析结果生成针对性的面试题目。

## 2. 功能说明

### 2.1 核心功能

| 功能 | 说明 |
|------|------|
| 题目生成 | 根据关键词和技术栈生成面试题 |
| 题库管理 | 内置多种题型的面试题库 |
| 难度筛选 | 支持按难度级别筛选题目 |
| 参考答案 | 提供题目的参考答案 |

### 2.2 题目类型

| 类型 | 说明 | 示例 |
|------|------|------|
| concept | 概念理解题 | 解释JavaScript闭包原理 |
| code | 手写代码题 | 实现一个防抖函数 |
| design | 系统设计题 | 设计一个秒杀系统 |
| system | 行为面试题 | 自我介绍 |

### 2.3 题目难度

| 难度 | 说明 |
|------|------|
| easy | 初级，适合1-3年经验 |
| middle | 中级，适合3-5年经验 |
| high | 高级，适合5年以上经验 |

## 3. 接口定义

### 3.1 generateQuestions(jdText, settings)

**功能**：生成面试题

**参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| jdText | string | 是 | - | JD文本内容 |
| settings | object | 否 | {} | 生成设置 |

**settings参数**：

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| count | number | 10 | 生成题目数量 |
| difficulty | string | 'all' | 难度级别筛选 |
| includeSystemDesign | boolean | true | 是否包含系统设计题 |
| includeCode | boolean | true | 是否包含手写代码题 |

**返回值**：

```javascript
{
  success: true,
  meta: {
    totalKeywords: 15,
    position: '前端开发工程师',
    experience: { required: 3 },
    generatedAt: '2026-05-19T12:00:00.000Z'
  },
  questions: [
    {
      id: 1,
      type: 'concept',
      question: 'React中的虚拟DOM是什么？',
      difficulty: 'easy',
      tags: ['虚拟DOM', '核心概念'],
      category: '框架',
      source: 'React',
      status: 'pending'
    }
  ]
}
```

### 3.2 getAnswer(questionId, questions)

**功能**：获取题目参考答案

**参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| questionId | number | 是 | 题目ID |
| questions | Array | 是 | 题目列表 |

**返回值**：

```javascript
{
  found: true,
  question: 'React中的虚拟DOM是什么？',
  type: 'concept',
  answer: '这是一道概念题...\n\n【解题思路】...'
}
```

## 6. 生成算法

### 6.1 题目生成流程

```
1. 解析JD文本
   ↓
2. 提取关键词和技术栈
   ↓
3. 按权重排序关键词
   ↓
4. 从题库匹配相关题目
   ↓
5. 根据设置筛选题目类型
   ↓
6. 添加系统设计和软技能题
   ↓
7. 打乱顺序并截取指定数量
   ↓
8. 分配题号并返回结果
```

### 6.2 关键词权重计算

```javascript
// 权重计算公式
finalScore = keywordWeight × matchCount × typeBonus

// 其中：
// - keywordWeight: 关键词基础权重
// - matchCount: 关键词在JD中出现次数
// - typeBonus: 题目类型加成（如手写代码题 × 1.2）
```

## 7. 使用示例

```javascript
// 引入模块
const { generateQuestions, getAnswer } = require('./services/question-generator.js')

// 生成面试题
const result = generateQuestions(jdText, {
  count: 10,
  difficulty: 'middle',
  includeSystemDesign: true,
  includeCode: true
})

if (result.success) {
  console.log('生成了', result.questions.length, '道题目')
  
  // 遍历题目
  result.questions.forEach(q => {
    console.log(`Q${q.id}: ${q.question}`)
  })
  
  // 获取参考答案
  const answer = getAnswer(1, result.questions)
  console.log('答案:', answer.answer)
}
```

## 8. 扩展指南

### 8.1 添加新题库

在 `config/index.js` 中的 `QUESTION_BANK` 对象添加新的题库：

```javascript
QUESTION_BANK.newCategory = [
  {
    type: 'concept',
    question: '新问题内容',
    difficulty: 'middle',
    tags: ['标签']
  }
]
```

### 8.2 添加关键词

在 `config/index.js` 中的 `KEYWORD_WEIGHTS` 对象添加新关键词：

```javascript
KEYWORD_WEIGHTS.languages.newLanguage = 1.0
```

### 8.3 自定义题目模板

在 `question-generator.js` 中的 `getAnswer` 函数添加新的答案模板：

```javascript
const answers = {
  newType: '新的答案模板...'
}
```
