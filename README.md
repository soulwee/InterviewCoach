# InterviewCoach - 程序员面试准备小程序

基于微信小程序的智能面试准备工具，通过解析招聘要求(JD)生成针对性的面试题目。

## 功能特性

- JD智能解析：自动提取职位要求、技能关键词
- 面试题生成：根据JD生成针对性面试题
- 模拟面试：支持多种面试题型
- 历史记录：保存面试记录便于回顾

## 技术栈

- 微信小程序原生框架
- 云开发能力
- NLP关键词提取算法

## 项目结构

```
├── miniprogram/           # 小程序主目录
│   ├── app.js            # 应用入口
│   ├── app.json          # 应用配置
│   ├── app.wxss          # 全局样式
│   ├── pages/            # 页面目录
│   ├── components/       # 组件目录
│   ├── services/         # 服务模块
│   ├── utils/            # 工具函数
│   └── docs/             # 开发文档
└── project.config.json   # 项目配置
```

## 快速开始

1. 克隆项目
2. 使用微信开发者工具导入项目
3. 配置云开发环境（如需后端功能）
4. 编译运行
